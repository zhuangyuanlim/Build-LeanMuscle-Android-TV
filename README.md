# 薄肌战神 - Android TV 原生安装包一键云编译工程

## 30秒获取 APK 步骤（免装 Android Studio）：
1. 在 GitHub 新建一个空白仓库（公开或私有均可）。
2. 将本压缩包解压后的所有文件（注意包含隐藏的 `.github` 文件夹）上传并提交（Commit）到仓库根目录。
3. 点击 GitHub 仓库顶部的 **Actions** 选项卡，工作流会自动开始编译（约 90 秒完成）。
4. 编译变绿勾后，点进该次运行，在页面最下方的 **Artifacts** 区域点击 **LeanMuscle-TV-APK** 即可下载可直接安装到电视的 `app-release.apk` 和 `app-debug.apk`！
